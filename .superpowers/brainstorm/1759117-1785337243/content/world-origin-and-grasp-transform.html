我建议的原点策略

A

保留冻结 Stage 的 /World 原点（推荐）

不移动 Stage、不改变现有 hash。所有 Grasp Editor、Bottle runtime 和 IK 报告显式保存 T_W→B、T_W→O、T_O→G、T_B→G，并做矩阵闭环误差检查。

B

把 /World 重新放到桌面或底座中点（不推荐）

表面更直观，但会改变冻结 Stage、所有现有坐标、截图和报告 hash； 也会把“坐标管理问题”变成“资产重写问题”。

进入 IK 以前必须输出的机器门

  • 四个 frame 的绝对 prim path 和各自 world matrix；
  • T_W→O × T_O→G 与直接 runtime gripper preview 的位姿误差；
  • T_W→B × T_B→G 回代后的 world pose 误差；
  • Lula 使用的 end-effector frame 与 Grasp Editor gripper frame 的固定变换；
  • 若两者不是同一个 frame，显式保存 T_EE→G，禁止默认单位矩阵；
  • 位置误差和姿态误差 gate 未通过时，不执行动态抓取。
