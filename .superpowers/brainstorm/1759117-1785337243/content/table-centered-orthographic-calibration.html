桌面上表面中心作为抓取任务世界原点

本页全部采用正投影，不使用透视。坐标来自冻结 Stage readback。 我将现有 USD 世界记为 Wᵁ，将桌面任务世界记为 Wᵀ，避免两个“世界”混淆。

建议定义
  • Oᵀ：桌面上表面的几何中心。
  • +Zᵀ：桌面法向向上。
  • +Xᵀ：从 follower_left 底座指向 follower_right 底座。
  • +Yᵀ：Zᵀ × Xᵀ，从而满足 Xᵀ × Yᵀ = Zᵀ。
正投影 1：顶视 XY（沿 −Zᵀ 看向桌面）
正投影 2：前视 XZ（沿 +Yᵀ 看）
正投影 3：侧视 YZ（沿 −Xᵀ 看）

两个世界 frame 的精确关系

Wᵁ = USD /World
Wᵀ = tabletop task world

采用 Wᵀ 后的抓取与 IK 变换

TWᵀ→O(t) × TO→G = TWᵀ→G(t)

TWᵀ→B−1 × TWᵀ→G(t) = TB→G(t) → Lula IK

中间换成桌面 frame 后，最终的 base-relative IK 目标在数学上应与直接使用 USD world 完全一致； 若不一致，说明变换链重复应用或漏乘了某个 frame。

这确实给出了可执行的 calibration 思路

  1. 测量或从经过确认的 CAD/安装图取得桌面上表面中心 Oᵀ。
  2. 用左右底座安装中心定义 +Xᵀ，方向为 left → right。
  3. 用桌面上三个不共线实测点拟合平面法向，选择向上的方向作为 +Zᵀ。
  4. 计算 +Yᵀ = Zᵀ × Xᵀ，然后重新正交化三个轴。
  5. 分别求出 T_Wᵀ→Bᴸ、T_Wᵀ→Bᴿ；不要假设两个底座完全平行或绝对对称。
  6. 运行时把 Bottle perception/CAD pose、Grasp Editor pose 和 IK 全部转换到同一 Wᵀ。
  7. 保存标定点、拟合残差、矩阵 determinant、正交误差和日期；缺少实测点时只标记为数字 Stage readback。
