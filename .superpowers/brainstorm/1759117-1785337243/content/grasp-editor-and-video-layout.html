必须先于 IK 通过的 Grasp Editor 几何门

  • object_frame：Bottle500 刚体上的稳定 frame；保存的是 gripper frame 相对它的 pose。
  • gripper_frame：必须与 Lula 使用的末端 frame 建立并验证固定变换，不能把 wrist/gripper link 名称想当然地混用。
  • position / orientation：来自同一瓶身截面；两指内侧区域在瓶轴两侧，接触中心线与 AB 垂直。
  • pregrasp_cspace_position：真实 runtime DOF 名称和已验证张开值，aperture 大于该截面直径。
  • cspace_position：真实闭合方向和合法范围；不能用镜像 finger 或 180° 临时旋转。
  • 先预览再 IK：open / close 都必须显示瓶子处在两指之间；失败就不调用 Lula。
