- “正式部署模型”、事实源版本、报告日期、报告版本和作者行采用相同规则；
- 行距一致，长文本不挤压相邻行。

## 3. 日文版结构

采用“独立日文版 + 共享事实数据 + 独立日文化图表”。

日文版共享以下不可变事实：

- 数据集统计；
- 保存模型信息；
- 训练与实验数量；
- 证据编号；
- 现场观察的证据等级；
- 缺失信息和结论边界。

日文版不得重新估算、改写或美化数字。若中文原文把某结果标为现场估计，日文版必须保留同等级限定。

日文版拥有独立的：

- LaTeX 主文件与章节文件；
- 日文化图表；
- 构建脚本；
- 验证结果；
- 日语审稿记录；
- 页面视觉审查记录。

## 4. 日文化范围

全部可见内容日文化，包括：

- 封面；
- 摘要和正文；
- 章节、目录、插图目录和表格目录；
- 表题、图题和图注；
- 科学图内部标签、标题、图例和轴标签；
- 表格单元格；
- “先说人话”“证据边界”“本阶段结论”等提示框；
- 附录、参考文献标题和缺失信息摘要。

以下内容保持不变：

- 数字；
- 单位；
- 证据编号；
- 训练步数；
- 参数量；
- 数据集规模；
- Git 提交编号；
- 已审计的专有名词和缩写。

## 5. 日文字体

采用用户确认的方案 A：

- 正文：`Noto Serif CJK JP`；
- 标题、表格、图内标签：`Noto Sans CJK JP`。

这两套字体已在本机安装，无需联网下载。XeLaTeX 必须显式选择 JP 字体族，不能依赖中文字体回退。

## 6. 表格与页面合同

日文版禁止一张表格跨页。

实现规则：

1. 普通表格使用不可分页的 `table` 与 `tabularx`；
2. 较宽的计划表优先放入横向页面；
3. 较长但可读的表格允许局部使用较小字号，但不得缩小到视觉审查无法阅读；
4. 若单表确实无法在一页内保持可读，应重新组织为两个语义独立、标题独立的表，而不是使用续表；
5. 禁止使用会自动拆页的 `longtable` 作为日文版最终表格；
6. 不允许表格裁切、越出页边距、标题与表格分离或只留下极少行的孤立页面。

## 7. 日语科技写作规范

报告使用科技报告常用的书面常体，避免敬体与常体混用。优先采用日本机器人与机器学习领域通用表达，例如：

- 模倣学習；
- 強化学習；
- 視覚・言語・行動モデル；
- 双腕ロボット；
- 実機評価；
- オフライン評価；
- チェックポイント；
- 行動チャンク；
- 時系列アンサンブル。

不得逐字照搬中文语序。长句应按日语逻辑拆分，主语省略必须不造成指代歧义。所有图题和表题应简洁说明“图表展示什么”，证据边界放入图注或正文，不重复堆叠。

## 8. 独立日语审稿

初稿完成后，启动独立子任务，由熟悉机器人学习、计算机视觉、模仿学习、强化学习和科技日语写作的审稿人复核。

审稿人检查：

- 科技术语是否符合日语通用习惯；
- 助词和搭配是否自然；
- 是否存在汉语式长句；
- 常体是否统一；
- 图题、表题和图注是否地道；
- 同一术语在全文是否一致；
- 证据边界是否因翻译而弱化；
- 数字和结论是否与中文版一致。

审稿人不直接改变事实和数字。主任务根据审稿意见逐项修改，并保存“意见—处理结果”记录。

## 9. 验证

### 9.1 自动验证

中文版和日文版都必须：

- 全量编译至少两次；
- PDF 可由 `pdfinfo` 正常读取；
- 无致命 LaTeX 错误；
- 无缺失图片；
- 无缺失引用；
- 无 `overfull`；
- 无字体缺失或错误回退；
- 关键数字与证据编号一致。

日文版额外检查：

- PDF 中不存在应翻译而残留的中文公共文字；
- 不存在 `longtable`；
- 表格数量与预期一致；
- 每张表格只出现在一个物理页面中。

### 9.2 视觉验证

把两份 PDF 的所有页面渲染为图片，由视觉模型逐页检查：

- 封面信息行基线；
- 图 1.1 相机箭头目标；
- 图 4.1 最后两个流程框间距；
- 日文字体、标点、换行和层级；
- 表格是否跨页、裁切或小到不可读；
- 图内文字是否重叠；
- 是否出现大面积异常留白；
- 图题、表题是否与内容同页；
- 横向页面方向是否正确。

发现问题后修改、重编译并重新检查对应页面。
