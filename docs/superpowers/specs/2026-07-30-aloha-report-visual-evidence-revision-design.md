# ALOHA 现阶段技术报告视觉与证据叙事修订设计

## 1. 目标

在不改变已核验事实、不虚构实验结果的前提下，对《ALOHA 机器人拧瓶盖项目现阶段技术报告》进行第二轮正式汇报版修订。修订重点是消除图中文字重叠和重复解释，补充真实数据平台截图，强化工作投入到阶段成果之间的逻辑链，并提高正文阅读舒适度。

## 2. 已确认的范围

- 保留附录 A，不删除其证据索引与关键数字表。
- 正文基准字号由 11pt 调整为 10pt；图内字号和已生成图片尺寸不随之缩小。
- 所有图采用“数据主体 + 合并图注”规则：
  - 图内仅保留标题、坐标、图例、数值、单位和必要的短标签；
  - 删除图内“这张图回答……｜边界……”式长句；
  - 将读图目的、主要信息和证据边界合并进正式图注；
  - 同一含义只出现一次。
- 逐图检查文字重叠、裁切、图例遮挡、数值标签越界、长标题、空白比例、分辨率和与相邻正文的语义重复。
- 保留报告事实核验标准，不把训练次数、损失下降或进程状态写成真机成功率。
- 结果分析采用“成果先行”的表达顺序：先说明已经形成的系统能力、工程闭环和工作投入，再用较简洁、建设性的方式说明仍需提高的环节。
- 不隐去会改变结论含义的限制；将“证据不足”更多表达为“下一阶段将通过标准化记录进一步量化”，同时保留现场估计与正式测试之间的边界。

## 3. 图 5.1 的确定改法

训练试验漏斗图删除以下图内长文本：

- “这张图回答：团队尝试了多少训练方向，多少运行真正走得足够远？”
- “边界：运行次数衡量工程迭代，不衡量模型能力。”
- 图内右下角关于 41 次尝试、运行状态和两个训练方向的说明段。

图内只保留：

- 五个漏斗阶段；
- 两个训练方向的图例；
- 各阶段数量；
- 横轴名称；
- 简短、可读的标题。

图注合并为一个不重复的完整表述：

> 图 5.1　训练试验漏斗。团队围绕瓶子分拣基础模型和冲洗/插入任务共开展 41 次训练尝试；该图体现工程迭代量与运行稳定性，运行状态不等同于模型真机任务成功。

“33 次中断、5 次失败、3 次标记结束”和“标记结束只代表进程状态”放入相邻正文或表格中，不再叠加在绘图区。

## 4. 全报告图表规则

建立逐图审查清单，对报告实际引用的每一张图记录：

- 图号和文件；
- 该图回答的唯一问题；
- 支撑的正文结论；
- 图内是否存在长句；
- 图内与图注是否重复；
- 是否有文字、图例、数值或标注重叠；
- 是否存在过多空白或跨页割裂；
- 数据来源和证据等级；
- 修改动作；
- 修改后的视觉检查结果。

已有图只在原始数据支持范围内重绘。新增图优先用于体现真实工作量和工程链条，例如数据采集规模、数据清洗检查量、训练运行谱系、保存模型审计项、平台功能覆盖、注意力样本量和强化学习离线研究规模。缺少真实数据时不生成对比曲线。

## 5. 数据平台截图设计

通过受审浏览器访问真实数据编辑平台，并把界面语言切换为日语。不得在报告中展示账户、密码、令牌、IP 地址、设备序列号或其他敏感信息。

计划采集两类浏览器可见区域截图：

1. **全部数据集合页面**
   - 只截取当前浏览器可见区域；
   - 展示项目/集合列表、数量、状态和主要筛选入口；
   - 使用报告侧标注说明数据如何被组织、检索和进入后续训练流程。

2. **单个瓶子集合详情页**
   - 选择真实的瓶子相关集合；
   - 页面应实际展示四路相机数据、机器人虚拟演示和时间轴；若真实页面布局不同，按真实界面记录，不重构或伪造；
   - 标注四路视角、机器人动作回放、时间轴、片段定位和标注入口；
   - 正文解释多视角和时间轴标注用于发现抓取方向、瓶盖状态、动作同步及关键阶段问题，从而提高训练数据的一致性。

原始截图单独保存，报告使用的标注版另存。只允许裁剪浏览器视口、增加编号、箭头、框和文字说明，不改动页面数据内容。

## 6. 叙事结构

正文强化以下因果链：

1. 任务难度：双臂协作、随机瓶堆、视觉定位、接触旋拧和长流程分箱；
2. 工程投入：采集软件、数据编辑平台、多批数据、训练运行、保存模型核验和现场集成；
3. 方法闭环：采集、清洗、标注、训练、部署、现场观察、问题回流；
4. 阶段能力：完成过完整动作链，具备连续工作和多条件处理的现场表现；
5. 证据等级：可复核数据、运行记录和现场估计分别陈述；
6. 下一年度：扩大高价值数据、提高基础模型、开展强化学习和毫米级插管研究。

第 7 章“结果分析与讨论”重排为：

- 已形成的能力与工程资产；
- 当前方法有效的原因；
- 对工作量和复杂性的综合说明；
- 仍可提升的典型场景；
- 下一阶段如何量化和解决。

失败模式不删除，但减少重复的否定句，不使用会夸大结论的模糊表达。

## 7. 字体与分页

- 文档类基准字号调整为 10pt。
- 图注保持 `small`，图内字号不变。
- 表格根据密度保留现有局部小字号。
- 重新编译后逐页渲染为图片，检查正文密度、图表占比、半空白页、孤行、表格越界和图注跨页。
- 对因字号变化造成的分页问题，通过调整浮动位置、图片宽度和段落衔接解决，不通过继续缩小图中文字解决。
