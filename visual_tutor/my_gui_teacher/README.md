# my-gui-teacher

Project-local stdio MCP server for the Visual Tutor system.

It exposes only high-level lesson tools. It deliberately does not expose arbitrary coordinate clicking, shell execution, sudo, Python execution, file deletion, or real robot control.

Example local test:

```bash
python3 visual_tutor/my_gui_teacher/server.py
```

Codex registration should point to:

```text
python3 /home/eii/project/openpi0.5-rtc-reward-learning/visual_tutor/my_gui_teacher/server.py
```
