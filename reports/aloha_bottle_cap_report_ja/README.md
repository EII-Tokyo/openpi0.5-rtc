# ALOHA ボトルキャップ開栓ロボット 現段階技術報告書（日本語版）

本ディレクトリは、中国語版で監査済みの数値とエビデンスを共有しつつ、本文、表、図中ラベルを日本語化した独立版である。実写真と教示フレームは内容を改変せず、注釈だけを日本語で再描画した。

## 使用環境

図の生成にはプロジェクト仮想環境（NumPy 2.4.0、Matplotlib 3.10.3）を使い、PDF は XeLaTeX で三回コンパイルする。本文には `Noto Serif CJK JP`、見出し・表・図には `Noto Sans CJK JP` を埋め込む。

## 図と PDF の再生成

プロジェクトルートから次を実行する。

```bash
make -C reports/aloha_bottle_cap_report_ja figures
make -C reports/aloha_bottle_cap_report_ja pdf
make -C reports/aloha_bottle_cap_report_ja verify
```

`make figures` は監査済み JSON/CSV と実画像から18種の目的別図を再生成する。`make pdf` は参考文献と相互参照を含めて三回コンパイルする。`make verify` は PDF の可読性、埋込み字体、未解決参照、欠落図、表の非分割契約、主要数値、空白ページを検査する。

## 表とエビデンスの契約

自動改ページする表環境は使わず、各表を一つの物理ページ内に置く。横長の計画表は見出し、説明、表本体を同じ横向きページへ配置する。現場の「1時間超」「約2本/分」は完全映像と計数台帳がないため概算であり、成功率として扱わない。
