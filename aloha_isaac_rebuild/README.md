# ALOHA1 Isaac Rebuild

This workspace is for a clean ALOHA1 Isaac Sim rebuild.

The first stage is a structural skeleton only. It intentionally contains no
robot meshes, physics schemas, cameras, replay hooks, controllers, or Trossen
numeric parameters.

Source roles:

- Trossen Stationary AI USD: structure reference only.
- NVIDIA Isaac Sim documentation: USD and Isaac semantic reference.
- Real ALOHA1 configuration and measurements: the only source for ALOHA1
  physical, control, and sensor values.
